# On-device check (Android)

Things only a real phone can confirm. Open **https://throbbingmember69.github.io/Exersise-Applet/** in Chrome.

## Install and storage
- [ ] Chrome menu → **Install app** (or "Add to Home screen"). It opens full-screen from the home-screen icon.
- [ ] More → Data & backup → Storage shows **Protected: Yes**. If not, tap **Protect my data** (this usually works once the app is installed).
- [ ] Turn on airplane mode and open the app from the icon: it loads, and you can log a set.

## Workout and rest timer
- [ ] Train → Start workout → Start. When asked, allow notifications.
- [ ] Log a set: the rest bar counts down and the screen stays on (wake lock).
- [ ] At the minimum rest the phone vibrates and beeps (with the app open).
- [ ] Log a set, then switch to another app: a "Rest done" notification arrives at the minimum rest. Tapping it returns to the logger.
- [ ] Lock the screen during rest: note whether the alert arrives on time. Android may delay it; keeping the app open with the screen on is the reliable mode.
- [ ] Finish → the summary shows next time's loads.

## Data
- [ ] More → Data & backup → **Save backup file** → share to Drive (or Files) and check the file is there.
- [ ] **Export CSV** → Workout sets → opens in Sheets.
- [ ] Arboleaf app → History → clock icon → Export → save the CSV. Then Data & backup → **Import from your smart scale** → pick the file → check the preview (columns, dates, units) → Import.
